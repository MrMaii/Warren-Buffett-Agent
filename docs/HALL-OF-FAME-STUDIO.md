# One room in HoloFame Studio

[HoloFame Studio](https://github.com/MrMaii/Hall-of-Fame-Studio), whose main
repository is named Hall of Fame Studio, is a local-first open-source project
for building and composing evidence-grounded persona Agents.

This standalone repository exists for direct use, inspection, contribution,
and portable integration. Inside the Studio, the same source fingerprint can
appear across:

- the Talent Market dossier;
- Persona Chat;
- project initiation and team selection;
- Leader and Reviewer assignment;
- group chat and handoffs;
- artifact, evidence, review, and revision flows;
- Manager Flow Graph and Proof Map surfaces.

The larger goal is not a gallery of celebrity chatbots. It is a governed
institution of distinct working minds. A product Agent can challenge an owner,
a researcher can reject a weak source, and a reviewer can force revision while
preserving attribution and the person behind the work.

Standalone publication never substitutes for Studio integration. The canonical
Agent source remains governed by the Hall of Fame Studio Foundry workflow.
