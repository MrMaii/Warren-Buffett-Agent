# Warren Buffett Deep Agent v0.1.0

Agent 002 enters the Hall of Fame.

This first public release packages the evidence-grounded Warren Buffett Agent as a standalone, installable decision system for business quality, valuation, capital allocation, downside discipline, and owner communication.

## Included

- 12 composable decision Skills with explicit routing and named artifacts.
- 46 registered sources, 56 atomic observations, and 11 behavior claims.
- A deterministic runtime quality gate and package contract tests.
- English and Simplified Chinese launch guides.
- A complete museum-editorial media kit: hero, launch poster, social card, dynamic demo, teaser, and five architecture diagrams.
- Reproducible fingerprinting and media-build scripts.

## Qualification boundary

This package is **repository-prequalified** against `buffett-plus-v1`. Director qualification remains pending. It is an educational decision-support system, not Warren Buffett, Berkshire Hathaway, or personalized financial advice.
